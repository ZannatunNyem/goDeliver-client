# 📦 GoDelivery

GoDelivery is a modern and responsive parcel delivery web application that allows users to send parcels quickly and conveniently. Users can browse available delivery services, enter parcel information, receive an instant checkout summary with the total delivery cost, and securely place delivery orders after authentication.

## 🌐 Live Demo

🔗 **Live Site:** https://nd-project-40242.web.app/

---

## 📖 Overview

GoDelivery simplifies the parcel booking process with an intuitive user interface and secure authentication. Users can sign in, submit parcel details, calculate delivery charges instantly, and confirm orders through interactive pop-up notifications.

---

## ✨ Features

-  User Authentication (Firebase)
-  Book parcel delivery services
-  Enter sender and receiver information
-  Automatic delivery cost calculation
-  Checkout summary with total price
-  Interactive notifications using **SweetAlert2**
-  Fast and responsive user interface
-  Mobile, tablet, and desktop friendly
-  Smooth navigation with React Router

## 🔐 Authentication

Users can securely access the application using Firebase Authentication.

After signing in, users can:

- 📦 Book parcel deliveries
- 📝 Submit parcel information
- 💰 View delivery cost calculations
- 🛒 Review checkout details before confirming an order

---

## 💰 Checkout System

GoDelivery automatically calculates the delivery charge based on the parcel information provided by the user. Before confirming an order, a checkout popup displays:

- Parcel Details
- Delivery Information
- Total Delivery Cost

Interactive confirmation messages are displayed using **SweetAlert2**.
