# 👤 Profile Card

## 📖 Overview
Profile Card is a simple frontend demo project built with **React** and **Vite**. Users can enter their information in a form, and upon clicking **Submit**, a profile card is generated and displayed instantly.

Since this is a frontend only project, the card data is **not stored**. Refreshing the page resets the application and removes the generated card.

## 🌐 Live Demo
🔗 https://profile-card-three-wine.vercel.app/

## 📝 Features
-  Enter profile information through a simple form
-  Generate a profile card instantly
-  Live preview after submitting


## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| React | UI Development |
| Vite | Fast development & build tool |
| Tailwind CSS | Styling |

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/profile-card.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📌 Note

This is a **frontend only demo project**. No backend or database is used, so generated profile cards exist only during the current session and disappear after the page is refreshed.
